### 🔬 Projetos em destaque

| Projeto | O que faz | Stack |
|---|---|---|
| [**ChaosID**](https://github.com/cybersantana83/ChaosID) | Perícia forense de cartões no Flipper Zero. Identifica protocolos LF/HF e classifica o risco de segurança de cada um. | `C` `Flipper Zero` |
| [**chaos-nfc**](https://github.com/cybersantana83/chaos-nfc) | Firmware NFC/RFID read-only para a linha M5Stack. Detecta o chip conectado (ST25R3916 / WS1850S) e identifica MIFARE, NTAG, DESFire. | `C++` `ESP32` `M5Stack` |
| [**fido2-nfc-scanner**](https://github.com/cybersantana83/fido2-nfc-scanner) | FAP para Flipper Zero que extrai metadados de autenticadores FIDO2 via NFC sem autenticação (AAGUID, versões, extensões). | `C` `FIDO2/CTAP2` |
| [**cyberlab-local**](https://github.com/cybersantana83/cyberlab-local) | Laboratório de pentest em Docker Compose com DVWA, Juice Shop, WebGoat, Kali, Metasploitable e alvo de enumeração SNMP/LDAP. Usado em sala de aula. | `Docker` `Pentest` |
